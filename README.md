# Nitebop – Neon Night

Nitebop ist ein kleines Mobile-Webspiel fürs Hochformat. Eine glänzende Kugel fliegt durch eine Neon-Nacht: tippen, springen, Röhren ausweichen und Münzen sammeln.

## Spielen

Im Browser öffnen:

https://hasanbeg99.github.io/nitebob/

Auf dem Handy im Hochformat spielen.

- Tippen startet das Spiel. Jeder weitere Tipp lässt die Kugel springen.
- Fliege durch die Lücken. Berührung mit einer Röhre oder dem Boden beendet den Lauf.
- Münzen in den Lücken geben eine Münze. Im Shop gibt es dafür neue Skins.
- Der Ton ist anfangs aus. Oben rechts einschalten.
- Nach Game Over: „Nochmal“ oder erneut tippen.

Am Rechner geht auch Leertaste, Pfeil nach oben oder W.

## Auf den Home-Bildschirm

Safari (iPhone): Teilen → „Zum Home-Bildschirm“.

Chrome (Android): Menü → „App installieren“ oder „Zum Startbildschirm hinzufügen“.

Danach startet Nitebop im Vollbild, auch ohne Browserleiste. Einmal online geöffnet, bleibt eine Version im Cache und lässt sich offline weiter spielen.

GitHub Pages liefert die Dateien aus dem Repository-Root. Dafür muss das Repository öffentlich sein.
